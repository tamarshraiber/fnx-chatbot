# Working Instructions

## Before Making Changes
- Explain the plan and why before changing anything.
- List every file to be created, modified, or deleted.
- Never modify files, install packages, or run commands that change files or system state without explicit approval.
- Approval applies only to the specific changes agreed upon. Ask again if the scope changes.
- Ask questions when requirements are unclear. Never guess or assume approval.

## How to Work
- Work incrementally, one task at a time.
- Avoid unrelated changes.
- Explain everything you do, why you do it, and how it works, step by step, in simple English.
- Explain code, technical concepts, and decisions in simple English.
- Communicate in English unless the user requests otherwise.

## After Each Task
- Summarize what changed.
- Explain how to test it.

## Creating CLAUDE.md
- Before creating this file, inspect the project without modifying anything, show the proposed contents, and wait for approval.
